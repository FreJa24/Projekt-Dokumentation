# Funktionen

- Die Seite zeigt eine Überschrift und einen kurzen Text.
- Darunter erscheint ein Weihnachtsmann, der im Kamin feststeckt. Das Bild wird aus `weihnachtsmann.svg` geladen.
- Unter dem Bild zeigt die Seite den HTML-Code aus meinem GitHub Gist.
