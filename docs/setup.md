# Einrichtung

1. Öffne den [Gist auf GitHub](https://gist.github.com/FreJa24/353e2f0f08465e81bba09f50dcdf35f0).
2. Klicke auf **Download ZIP** und entpacke die ZIP-Datei.
3. Öffne `index.html` per Doppelklick im Browser.

Die Dateien `index.html` und `weihnachtsmann.svg` müssen im gleichen Ordner liegen. Für den eingebetteten Gist-Code brauchst du eine Internetverbindung.
